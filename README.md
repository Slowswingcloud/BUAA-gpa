# 北航软件学院推免 GPA 计算器

一个 Vue 3 + Vite 小网页，用于按《软件学院推荐优秀应届本科毕业生免试攻读研究生的平均学分绩点成绩规则说明（适用 2024 级）》计算推免平均学分绩点。

仓库内已内置 **2024 级软件工程专业推免课程基础数据集**（来自该说明的表 1、表 2），打开页面即可直接填写成绩。

## 运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 生产构建（输出到 dist/）
```

## 计算规则

- 百分制：60 分以下绩点为 0；60 到 100 分使用 `课程绩点 = 4 - 3 * (100 - X)^2 / 1600`。
- 五级制：优秀 4，良好 3.5，中等 2.8，及格 1.7，不及格 0。
- 考查课（两级分制通过 / 不通过）：不累计学分绩点。
- 总 GPA：所有计入课程按 `课程学分绩点 = 课程绩点 × 学分数` 累加后除以总学分。

## 基础数据集

- 课程数据定义在 `src/courseData.js`，包含课程代码、中文课程名称、学分、开课学期、所属课程模块与框架组。
- 页面按开课学期分组显示（大一上 → 大三下），共 65 条记录，覆盖表 2 全部课程。
- 每门课程都可单独调整「成绩类型、成绩、学分、是否计入」，可增删自定义课程。

### 默认是否计入

| 课程类别 | 默认 | 说明 |
| --- | --- | --- |
| 基础课、通修课、核心专业类 | 计入 | 14 门核心专业课、6 门思政课、基础课全部计入 |
| 外语课 | 计入 | 表 2 列出 9 学分（英语 A/B 各 2 门 + 阅读、写作），要求 ≥6 学分，未修读的可手动取消勾选 |
| 专业方向课（限修） | 不计入 | 需自行选取 ≥6 学分，可逐门勾选，或用「计入全部方向课」一键勾选后手工排除 |
| 英文科技写作（软件工程） | 计入 | 表 1 要求 1 门 |
| 跨文化交流、软件工程伦理与职业规范、学科前沿讲座 | 计入学分但不计绩点 | 勾选状态用于统计「框架进度」，成绩类型为考查课，不参与 GPA |
| 综合素养课（航空航天概论B 等 3 门） | 不计入 | 要求通过课程考核即可 |
| 一般专业必修课（4 门） | 不计入 | 与核心专业类同名的 4 门，另行为「要求通过课程考核」 |

> 「计入」勾选框控制该课程是否参与 GPA；考查课（两级分制）即使勾选也不计绩点，只用于提示是否已通过。

### 基础课数学分班方案

表 2 的「数理基础课」列出两套数学课程（数学分析 A 方案 / 工科数学分析 B 方案），页面顶部可切换：

- **方案 A**：工科数学分析（1）（2）、工科高等代数、基础物理学A(1)、基础物理实验(1)
- **方案 B**：工科数学分析（1）（2）、基础物理学（1）（2）、基础物理实验(2)
- **概率统计A** 与 **工程基础课 4 门**（程序设计基础、电子设计基础训练、离散数学（信息类）、数据结构与程序设计（信息类））两套方案相同。

选择某一方案后，另一方案的课程会显示「A/B 方案课程」标记并自动不计入；顶部的「推免框架进度」会实时给出「数理基础课 6 门 / 工程基础课 4 门」等达标情况。

## 数据来源与已知取舍

原始文件：`rule.pdf`（软件学院推荐优秀应届本科毕业生免试攻读研究生的平均学分绩点成绩规则说明--2024级-（修订版）），纯文本提取结果保存在 `tools/rule-layout.txt`。

需要人工确认的两处：

1. **外语课**：表 1 要求「外语课 6 学分」，表 2 列出 9 学分（英语 A/B 共 4 门 + 英语阅读（3）、英语写作（3））。数据集默认全部计入，请按本人实际修读情况取消勾选。
2. **思政课**：说明提到「概论课（大类内部）（七选一）」，该课未在表 2 中给出具体的子课程，因此数据集未收录，仅保留表 2 中 6 门思政必修课。

## 自检脚本

```bash
node tools/selfcheck.mjs   # 校验数据集、绩点换算、框架统计，并编译 SFC 模板
node tools/ssr-check.mjs   # 用 @vue/server-renderer 真正渲染组件，校验课程行数与学期分组
```

脚本结果分别输出到 `tools/selfcheck-result.txt` 与 `tools/ssr-check-result.txt`。
